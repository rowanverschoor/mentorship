Step 1: Check the backend runs
1. cd backend/WeatherApi && dotnet run
2. Open the URL it prints plus /weatherforecast. You'll see random demo JSON. Stop it with Ctrl+C.

Step 2: Check the frontend runs
1. cd frontend && npm install (already done, so it may do nothing)
2. npx ng serve and open http://localhost:4200. You should see the default Angular page.

Step 3: Test the API Ninjas call by itself
1. Run curl -H "X-Api-Key: YOUR_KEY" "https://api.api-ninjas.com/v1/weather?lat=34.09&lon=-118.41".
2. Confirm you get weather JSON back before writing any code. This is already done for you.

Step 4: Store the key safely
1. Generate a new key on the API Ninjas site, since the old one was pasted into this chat.
2. In backend/WeatherApi, run dotnet user-secrets init.
3. Run dotnet user-secrets set "ApiNinjas:Key" "YOUR_NEW_KEY".
4. Check it with dotnet user-secrets list.

Step 5: Write the backend /weather endpoint in Program.cs
1. Register builder.Services.AddHttpClient(); before builder.Build().
2. Replace the /weatherforecast route with app.MapGet("/weather", ...). It takes lat and lon query parameters.
3. Inside it, use an injected HttpClient to call https://api.api-ninjas.com/v1/weather?lat=...&lon=.... Send the key from builder.Configuration["ApiNinjas:Key"] in the X-Api-Key header, and return the JSON.
4. Update launchUrl in Properties/launchSettings.json to weather?lat=34.09&lon=-118.41.
5. Test with curl "http://localhost:5297/weather?lat=34.09&lon=-118.41". It needs no key header, because the backend adds it.

Step 6: Allow the frontend to call the backend (CORS) in Program.cs
1. Add builder.Services.AddCors(...) with a policy that allows the origin http://localhost:4200.
2. Add app.UseCors(); after app.Build().

Step 7: Enable HTTP in Angular in frontend/src/app/app.config.ts
1. Import provideHttpClient from @angular/common/http.
2. Add provideHttpClient() to the providers array.

Step 8: Build the UI in frontend/src/app/app.component
1. Add two inputs, latitude and longitude, plus a button.
2. Inject HttpClient and call GET http://localhost:529n the button is clicked. Use your actual backend port.
3. Store the result in a class property and show it in the template.
4. Import FormsModule if you use [(ngModel)] for the i

Step 9: Try the whole flow
1. Run the backend and ng serve together.
2. Enter lat and lon and check that weather appears.
3. If it fails, check the browser dev tools Network tab. A CORS error means Step 6 is wrong.

Optional later: add geocoding in the backend so users can type a place name instead of coordinates.
